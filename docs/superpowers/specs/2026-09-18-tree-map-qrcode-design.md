# 校園樹木 QRCode 量測登記系統 — 設計規格

日期:2026-09-18

## 背景與目標

南港高工「校園樹木地圖」課程計畫,需要:
- 全校樹木建立地圖與編號
- 土木科學生使用測角儀,以三角函數法(量測仰角＋水平距離)實地測量樹高,並記錄樹圍
- 每棵樹旁貼 QRCode,學生掃描後直接在該樹的專屬頁面登記數據,系統自動計算樹高
- 每學期/每年皆會重新量測同一批樹,需保存歷年數據以觀察成長趨勢
- 老師需要一個網站,同時也要能像 App 一樣加到平板桌面使用(PWA)

## 使用情境限制(關鍵約束)

- 學生使用**校方統一登記的平板**(非學生個人帳號設備),平板**只有校園 WiFi、沒有行動電信數據**
- 校園部分角落 WiFi 收訊差,會出現完全離線的情況,需視為常態而非例外
- 「登入帳號」是設備/公用帳號,不能用來識別「是哪個學生填的」

## 與現有平台的關係

已查證「全國校園樹木資訊平台」(edutreemap.moe.edu.tw) 僅提供公開查詢型 API(`GetMapIndex`、`GetMapSearch` 等),未提供第三方寫入介面。本系統**獨立開發**,不依賴該平台;未來若需要,由老師手動將資料匯出成 Excel 回填官方平台。

## 架構

- **前端**:PWA(HTML/JS + manifest.json + service worker),可加到平板桌面、全螢幕開啟、支援完全離線運作
- **資料庫**:Google Sheet(老師可隨時直接開啟檢視/編輯/匯出,不依賴自建資料庫,降低長期無人維護的風險)
- **API 層**:Google Apps Script Web App(`doGet`/`doPost`),原生支援 Google Workspace 網域限制登入
- **Hosting**:前端獨立部署(如 GitHub Pages),Apps Script 只作為資料 API,不承載前端頁面

## 核心元件

1. **樹木主檔管理(教師後台)**
   - 建立/編輯樹木資料:編號、樹種、GPS 座標
   - 一鍵產生每棵樹的專屬網址(如 `.../tree/A-023`)與對應 QRCode 圖檔,供列印貼牌

2. **學生掃碼填寫頁(PWA 主功能)**
   - 掃碼 → 進入該樹專屬頁 → 帳號登入驗證(限校網域,僅作外部路人門檻)
   - 表單內**手動輸入姓名＋班級座號**(識別實際填寫人,不依賴登入帳號)
   - 輸入測角儀角度、水平距離 → 前端即時以三角函數算出樹高
   - 輸入樹圍 → 送出

3. **歷史紀錄與成長趨勢**
   - 每棵樹頁面下方顯示歷次測量的樹高/樹圍趨勢折線圖(依時間排序,支援跨學期/跨年比較)

4. **校園總覽地圖**
   - 仿 edutreemap 呈現全校樹木點位,點選跳轉單棵樹頁面

5. **資料匯出**
   - 教師後台一鍵匯出 Excel,供未來手動填回官方平台

## 資料流程

```
掃碼
  → PWA 載入對應樹 ID(離線快取的殼層立即可顯示)
  → 帳號網域驗證(僅作為外部路人門檻)
  → 學生填寫:姓名/班級座號 + 角度 + 水平距離 + 樹圍
  → 前端即時以三角函數算出樹高
  → 送出:
      有網路 → 直接 POST 到 Apps Script Web App,寫入 Google Sheet
      無網路 → 先存本機(IndexedDB),標記為「待同步」
  → 偵測到網路恢復時,背景自動重送「待同步」佇列
  → 該樹頁面重新讀取歷史資料,更新趨勢圖
```

## 資料模型(Google Sheet 欄位)

**樹木主檔表**:樹編號、樹種、GPS 座標、建立日期

**量測紀錄表**(可多筆對應一棵樹):樹編號、量測時間戳、填寫人姓名、填寫人班級座號、仰角、水平距離、計算後樹高、樹圍、同步狀態

## 錯誤處理與離線

- **完全離線可用**:表單頁面本身(含計算邏輯)由 service worker 快取,即使無網路也能完整填寫與計算,僅送出動作延後
- **待同步佇列**:離線送出的資料存 IndexedDB,標記時間與樹 ID;偵測到網路後自動背景同步,同步成功才從佇列移除
- **重複送出防呆**:同一樹同一填寫人同一天重複送出時,提示「今天已測過,是否覆蓋」
- **輸入防呆**:角度需介於 0~90 度、水平距離需大於 0,前端擋下不合理數值並提示
- **登入失敗**:非校網域帳號導向說明頁,要求使用學校 Google 帳號登入

## 測試重點

- 三角函數計算邏輯單元測試(含邊界角度、邊界距離)
- 離線佇列同步測試:模擬離線送出 → 恢復網路 → 驗證資料正確寫入且不重複
- 網域登入限制測試:非校網域帳號應被拒絕存取
- 離線快取測試:斷網狀態下開啟已快取過的樹頁面,表單仍可完整操作
