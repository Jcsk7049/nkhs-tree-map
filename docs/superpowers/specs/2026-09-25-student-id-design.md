# 學號自動轉換 — 設計規格

日期:2026-09-25 狀態:待使用者確認

## 目標
學生識別改用 8 碼學號(取代自由格式的「班級座號」),系統自動拆出入學年/科別/班級/座號顯示,讓老師貼名單、學生輸入時都能當場發現打錯。

## 學號格式
| 位置 | 意義 | 例 `11205071` | 規則 |
|---|---|---|---|
| 1–3 | 入學年 | `112` | 3 位數字 |
| 4–5 | 科別 | `05` → 土木科 | 2 位數字;查不到代碼表 → 顯示「05 科」 |
| 6 | 班級 | `0` → 忠班 | **只接受 0(忠)、1(孝)** |
| 7–8 | 座號 | `71` → 71 號 | 2 位數字 |

- 合法 = 正規化(去空白)後符合 `^\d{5}[01]\d{2}$`;其他一律「格式不對」。
- 顯示文字:`112 級 土木科 忠班 71 號`。
- 科別代碼表目前只有 `05 = 土木科`,放在單一常數,之後補科名只改一處。

## 刻意不改
- 內部欄位名 `classNo` / `studentClassNo` 不改名:平板 IndexedDB 裡離線暫存的量測用這個欄位名,改了舊佇列會送不出去。
- 通行碼、雜湊(`pepper|學號|碼`)、連錯鎖定邏輯不動。
- `verifyStudent` 不加格式檢查:格式錯的學號本來就查不到名簿,回同一個 `STUDENT_REJECTED`,不額外洩漏資訊。
- 既有 Sheet 的標題列不自動改(`getOrCreateSheet` 只在新建時寫標題);要改由使用者手動把 A1 改成「學號」。
- **Excel 匯出分欄移到功能 2**(現有匯出是每棵樹的公開彙總,不含學生資料)。

## 相容性
- Sheet 裡舊的測試學生(`10101`、`111`、`112` 等)不合新格式:量測頁前端會擋、名單頁無法再匯入,等於停用;使用者本來就要刪。
- 前端先上、後端還沒重新部署時:名單頁前端已擋格式,不影響使用;後端檢查是第二道防線。
