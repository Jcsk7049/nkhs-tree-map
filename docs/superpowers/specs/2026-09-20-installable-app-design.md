# 可安裝的整合 App — 設計

日期:2026-09-20 ｜ 狀態:待使用者審閱

## 目標
把現在 6 個獨立網頁整合成**一個可安裝到手機／平板主畫面的網頁 App(PWA)**,學生與老師共用同一個入口,不再零散。不上架 App Store / Google Play。

## 現況(事實)
| 項目 | 現況 |
|---|---|
| 頁面 | `index / tree / teacher / roster / map / qrcodes` 共 6 頁,各自獨立,老師頁靠「← 教師端」返回 |
| 安裝設定 | `manifest.json` 只有 192px 圖示、`start_url` 指向 `tree.html`;只有 `tree.html` 有 `<link rel="manifest">` |
| iOS | 沒有 apple-touch-icon |
| 離線 | Service Worker 只快取學生頁(`tree.html` 與其模組),老師頁與地圖不在內 |
| 老師登入 | 每個老師頁各自跑一次 `requireTeacher`,憑證存 sessionStorage,Google ID Token 約 1 小時過期 |
| 學生 | 只能掃 QR 進 `tree.html?treeId=…`,沒有「自己選樹」的入口 |

## 不變的部分(硬限制)
- 後端 API、通行碼雜湊、連錯鎖定、教師名單驗證**完全不改**。
- 已印出的 QR(`tree.html?treeId=…`)必須繼續可用。
- `src/config.js` 仍是設定單一來源。
- 學生離線暫存(IndexedDB 佇列)行為不變。

## 設計

### 1. 入口與導覽
- 新增 `public/app.html` 為唯一入口與 `start_url`。首頁兩個大按鈕:**我是學生**、**我是老師**。
- 學生模式底部分頁:**量測**、**樹木**(地圖唯讀著色)、**我的紀錄**。
- 老師模式底部分頁:**名單**、**地圖**、**QR 標籤**。
- 分頁切換不重新載入整頁(單頁殼層),各分頁內容沿用現有純函式模組(`src/*.js`)。

### 2. 學生模式
- 不需 Google 登入;通行碼仍是**每次送出**時驗證。
- 「量測」可從 QR 帶入樹號,也可從「樹木」分頁選樹(階段 2)。
- 「我的紀錄」只顯示該裝置離線佇列與最近送出結果;**不**提供跨裝置查詢(後端沒有依學生查紀錄的公開介面,也不新增,避免洩漏個資)。

### 3. 老師模式
- Google 登入在殼層做**一次**,各分頁共用同一個 `idToken`。
- **登入持續時間的誠實說明**:Google ID Token 約 1 小時過期,關閉 App 後 sessionStorage 也會清掉。因此不是「登入一次永遠有效」,而是**同一次使用期間不必每個分頁重登**;過期時顯示明確提示並重新登入。若之後要更長效,需後端改發自己的工作階段憑證(不在本次範圍)。
- 未登入時老師分頁只顯示登入閘門,不載入名單資料(真正的保護仍在後端)。

### 4. 安裝與離線
- `manifest.json`:`start_url` 改 `./app.html`,補 512px 圖示與 maskable 圖示,補 `id`、`scope`。
- 各頁加 `apple-touch-icon` 與 `theme-color`。
- Service Worker 快取範圍擴大到殼層與其模組(仍維持 `swCacheList.js` 與 `sw.js` 逐字一致的測試守門)。
- 老師頁離線只保證「能開啟殼層並看到需要連網的提示」;名單與量測寫入本來就需要連網,不做離線。

### 5. 相容
- `tree.html?treeId=…` 保留;開啟時若偵測到可用殼層,導向 `app.html#/measure?treeId=…`,否則照舊運作。
- 舊網址 `teacher.html / roster.html / map.html / qrcodes.html` 保留為導向頁,不讓舊書籤失效。

## 分階段(每階段可獨立上線)
1. **殼層與安裝**:`app.html`、底部導覽、共用登入、manifest / 圖示 / SW 擴大、舊網址導向。
2. **學生免掃 QR 選樹**:「樹木」分頁列出官方樹木(用既有 `data/nkhs-trees.json`),選樹後進「量測」。
3. **Excel 匯出**與**教師名單管理介面**(解除單一鎖定按鈕、教師信箱管理)。

## 錯誤處理
- 後端逾時(已有 30 秒上限)與登入過期:在殼層統一顯示提示,不讓分頁各自卡住。
- 安裝不支援的瀏覽器(iOS Safari 無安裝提示):首頁顯示「加入主畫面」的文字說明。

## 測試
- 單元:路由解析、分頁狀態、共用登入(過期／離線)、SW 清單與 `sw.js` 一致。
- 相容:舊 QR 網址與舊教師頁網址導向正確。
- 實機:iOS Safari、Android Chrome 安裝並離線開啟;老師登入後跨分頁不重驗;學生送出與離線補送。

## 不在範圍
- 上架 App Store / Google Play、推播通知、跨裝置學生紀錄、後端工作階段憑證。

## 待使用者拍板
- 首頁與圖示的視覺風格(沿用現在綠色 `#2e7d32`,或另訂)。
- 階段順序是否要調整(例如 Excel 匯出提前)。
