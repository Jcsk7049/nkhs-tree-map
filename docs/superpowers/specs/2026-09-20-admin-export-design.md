# 匯出與教師管理(階段 3)— 設計

日期:2026-09-20 ｜ 狀態:使用者已同意(對話中)｜ 上層:`2026-09-20-installable-app-design.md`

## 目標
1. 老師一鍵把「每棵樹的最新量測」匯出成 Excel 可開的檔案,回填官方平台。
2. 老師不用手動改 Google Sheet,就能解除學生鎖定、管理可登入的老師信箱。

## 決定(對話中已確認)
| 項目 | 決定 |
|---|---|
| 匯出內容 | 每棵樹一列的最新量測(不含學生姓名),來源為公開摘要 API,**不改後端** |
| 匯出格式 | CSV + UTF-8 BOM(Excel 直接開,中文不亂碼);`.xlsx` 需內建函式庫,本次不做 |
| 匯出欄位 | 官方樹號、樹種、最新樹高(m)、樹圍(cm)、量測時間(台灣)、量測筆數 |
| 匯出選項 | 「只匯出已有量測的樹」,預設勾選 |
| 解除鎖定 | 名單列表回傳 `locked`;被鎖定的學生顯示 🔒 與「解除鎖定」;只清連錯計數,不動通行碼 |
| 教師信箱管理 | 新增/移除;信箱轉小寫、驗格式、不重複;**不能移除自己、不能移除最後一位**;上限 100 位 |
| 信任模型 | 所有老師權限相同,任何老師都能增刪其他老師(不分管理員) |
| 入口 | 教師端新增第 4 分頁「管理」(`admin.html`:匯出 + 教師帳號) |

## 後端(`apps-script/Code.gs`,需使用者重新貼上並部署)
- `roster-list` 每位學生多 `locked: boolean`(用 `cache.getAll` 分批 ≤100 查連錯計數;快取失敗視為未鎖定)。
- `roster-unlock {classNo}`:學生不存在 → `VALIDATION_FAILED`;成功 → 移除該生連錯計數。
- `teacher-list` → `{emails: string[]}`(小寫、略過空列)。
- `teacher-add {email}`:格式(`^[^\s@]+@[^\s@]+\.[^\s@]+$`、≤254)、已存在回 `duplicate:true`、達上限拒絕;以 ScriptLock 保護;寫入用純文字格式與 `sanitizeCellText`。
- `teacher-remove {email}`:不能是呼叫者自己;找不到 → 錯誤;名單只剩 ≤1 位 → 拒絕;以 ScriptLock 保護。
- 既有動作、學生流程、公開摘要**行為不變**。

## 前端
- `src/exportCsv.js`:`csvEscape`、`formatTaiwanTime`、`buildTreeCsv`(純函式,含公式注入防護與 BOM)。
- `public/roster.html`:被鎖定顯示 🔒、「解除鎖定」按鈕。
- `public/admin.html`:匯出區(載入官方樹木 + 公開摘要 → 下載 CSV)、教師帳號區(列表、新增、移除,自己那列不顯示移除)。
- 殼層 `TEACHER_TABS` 加 `管理`;快取升 v15;`admin.html` 需登入,不進離線快取。
- 後端尚未重新部署時,新動作回「不認得的動作」→ 前端顯示明確提示,其他功能不受影響。

## 風險
- 老師被誤移除:自己與最後一位受保護;其他老師誤刪可再新增。
- 匯出資料是公開摘要(5 分鐘快取),剛送出的量測最多晚 5 分鐘出現;頁面標示「資料更新時間」。
- 公式注入:CSV 字串欄以 `= + - @` 開頭者補單引號。

## 測試
- 後端:沿用 `tests/codeGs.test.js`(vm 載入真檔 + 假 Sheet/Cache)。
- 前端:純函式單元測試;頁面為原始碼層級檢查 + 使用者 Chrome 實測。
